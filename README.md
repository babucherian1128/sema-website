# SEMA Website

Static public website for the South Edmonton Malayalee Association.

## GitHub Pages

The publishable site lives in the `docs/` folder so GitHub Pages can serve the public website without exposing the unfinished local `admin/` prototype.

To publish from GitHub Pages:

1. Open the repository settings.
2. Go to `Pages`.
3. Set the source to `Deploy from a branch`.
4. Select the `main` branch and the `/docs` folder.
